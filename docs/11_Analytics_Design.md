# Analytics Design

## 1. Introduction

This document describes the analytics and reporting design for the
Limit Order Book & Trade Execution Engine.

The system stores order and trade data in PostgreSQL and uses Power BI
for analytics and visualization.

The Version 1 dashboard focuses on basic order and trade metrics.

---

## 2. Analytics Flow

```text
Spring Boot
    ↓
PostgreSQL
    ↓
Power BI
    ↓
Analytics Dashboard
```

PostgreSQL acts as the primary source of persisted order and
trade data.

---

## 3. Data Sources

The dashboard primarily uses:

- `orders`
- `trade`

The `orders` table provides order-related information such as:

- Order Type
- Symbol
- Quantity
- Remaining Quantity
- Price
- Order Status

The `trade` table provides:

- Symbol
- Executed Price
- Executed Quantity
- Buy Order
- Sell Order

---

## 4. Dashboard Metrics

The Version 1 Power BI dashboard provides:

### Total Orders

Displays the total number of persisted orders.

### Total Trades

Displays the total number of executed trade records.

### BUY vs SELL Distribution

Shows the distribution of orders between BUY and SELL.

### Order Status Distribution

Shows orders grouped by their current status:

- OPEN
- PARTIALLY_FILLED
- FILLED

### Executed Trade Volume by Symbol

Shows total executed trade quantity grouped by trading symbol.

---

## 5. Analytics Data Flow

```text
User
  ↓
REST API
  ↓
Spring Boot
  ↓
Order / Trade Processing
  ↓
PostgreSQL
  ↓
Power BI Dashboard
```

The dashboard uses persisted database records generated by
the application.

---

## 6. Version 1 Scope

The analytics implementation supports:

- Order count
- Trade count
- BUY / SELL distribution
- Order status distribution
- Executed trade volume by symbol
- PostgreSQL integration
- Power BI visualization

---

## 7. Dashboard Design

The Version 1 dashboard contains visualizations for:

```text
+-------------------+-------------------+
|   Total Orders    |   Total Trades    |
+-------------------+-------------------+
| BUY vs SELL       | Order Status      |
| Distribution      | Distribution      |
+-------------------+-------------------+
| Executed Trade Volume by Symbol        |
+----------------------------------------+
```

The dashboard provides a quick overview of order activity,
trade activity, order-side distribution, order status, and
executed trade volume by symbol.

---

## 8. Current Limitations

Version 1 does not provide:

- Real-time dashboards
- Live market data
- Portfolio analytics
- Profit and Loss analytics
- Real-time WebSocket updates

These capabilities are outside the current scope.

---

## 9. Design Goal

The analytics design provides a simple and clear way to visualize
trading activity using the application's persisted order and
trade data.
