# High-Frequency Trading (HFT) Order Matching Engine

A backend simulation of an electronic stock exchange implementing asynchronous order processing, Price-Time Priority matching, thread-safe order management, and analytics-ready trade data.

---

## 🚀 Tech Stack

- Java 21
- Spring Boot
- Spring Security (JWT)
- PostgreSQL
- Spring Data JPA
- Maven
- Power BI
- Git & GitHub
